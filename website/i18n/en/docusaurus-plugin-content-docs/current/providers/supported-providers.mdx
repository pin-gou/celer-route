# Supported providers

celer-route ships built-in support for 40+ providers, covering international
mainstream LLMs, Chinese-domestic large models, local self-hosted inference
servers, and multimodal generation models. Every provider is consumed via the
OpenAI-compatible API — the same interface, any model or provider.

For per-provider details, configuration steps, and FAQ, see the corresponding
`/workspace/providers` pages or the GitHub repo docs. Below is the list of
built-in providers by category.

:::info More info

- Each provider's model list, whether an API key is required, and
  configuration steps can be viewed and configured under **Model Providers
  → Add Provider** in the Web UI
- In addition to built-in providers, celer-route supports **custom
  providers** (OpenAI-compatible, derived from a base provider) and custom
  models
- The list above is sourced from `StandardProviders` in
  `core/schemas/bifrost.go`; for the latest list please defer to the
  provider catalog in the Web UI
