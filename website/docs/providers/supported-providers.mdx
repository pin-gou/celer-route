# 支持的提供商

celer-route 内置支持 40+ 提供商，覆盖国际主流 LLM、国内大模型、本地自托管
推理服务与多模态生成模型。所有提供商统一通过 OpenAI 兼容 API 使用——同一套
接口，任意切换模型与提供商。

各提供的详细说明、配置步骤与常见问题，请查看对应的 `/workspace/providers` 页面
或 GitHub 仓库文档。下面按类别罗列内置提供商。

:::info 更多信息

- 每个提供商的模型列表、是否需要 API Key、配置步骤，可在 Web UI 的
  **模型提供商 → 添加提供商** 中查看与配置。
- 除内置提供商外，celer-route 还支持**自定义提供商**（OpenAI 兼容协议，
  基于上述基础提供商派生）与自定义模型。
- 以上列表来自 `core/schemas/bifrost.go` 的 `StandardProviders`，如需最新
  列表请以 Web UI 中的提供商清单为准。
