# Coze (国际版)

字节跳动 Coze 国际版的 OpenAI 兼容 API 接入。

## 配置

```json
{
  "providers": {
    "coze": {
      "network_config": {
        "base_url": "https://api.coze.com"
      }
    }
  }
}
```

## API Key

在 [Coze 设置](https://www.coze.com/settings/api) 创建 API Key。

环境变量：`COZE_API_KEY`

## 模型

Coze 代理第三方模型，如 `claude-3-7-sonnet-20250514`、`gpt-4o` 等。

## 支持的请求类型

- 聊天补全（Chat Completion）
- 流式聊天补全（Chat Completion Streaming）
- 模型列表（List Models）

## 限制

- 不支持文本补全（Text Completion）
- 不支持 Embedding
- 不支持图片生成
