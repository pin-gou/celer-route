# 小米 MiMo

小米 MiMo 云服务大模型的 OpenAI 兼容 API 接入。

## 配置

```json
{
  "providers": {
    "xiaomi_mimo": {
      "network_config": {
        "base_url": "https://api.xiaomimimo.com"
      }
    }
  }
}
```

## API Key

在 [小米 MiMo 控制台](https://xiaomimimo.com/console/api-keys) 创建 API Key。

环境变量：`XIAOMI_MIMO_API_KEY`

## 模型

支持动态模型列表，模型通过 `/v1/models` 自动发现。

## 支持的请求类型

- 聊天补全（Chat Completion）
- 流式聊天补全（Chat Completion Streaming）
- 模型列表（List Models）

## 限制

- 不支持文本补全（Text Completion）
- 不支持 Embedding
- 不支持图片生成
