# 阶跃星辰 (StepFun)

跃问（StepFun）大模型的 OpenAI 兼容 API 接入。

## 配置

```json
{
  "providers": {
    "stepfun": {
      "network_config": {
        "base_url": "https://api.stepfun.com"
      }
    }
  }
}
```

## API Key

在 [阶跃星辰开放平台](https://platform.stepfun.com) 创建 API Key。

环境变量：`STEPFUN_API_KEY`

## 模型

- `step-3.7-flash`
- `step-3-pro`
- `step-1v`（视觉模型）

## 支持的请求类型

- 聊天补全（Chat Completion）
- 流式聊天补全（Chat Completion Streaming）
- 模型列表（List Models）

## 限制

- 不支持文本补全（Text Completion）
- 不支持 Embedding
- 不支持图片生成
