# 魔搭 ModelScope

阿里云 ModelScope（魔搭）开源模型平台的 OpenAI 兼容 API 接入。

## 配置

```json
{
  "providers": {
    "modelscope": {
      "network_config": {
        "base_url": "https://api-inference.modelscope.cn"
      }
    }
  }
}
```

## API Key

在 [ModelScope 我的密钥](https://modelscope.cn/my/myAccessKey) 创建 API Key。

环境变量：`MODELSCOPE_API_KEY`

## 模型

支持动态模型列表，通过 `/v1/models` 自动发现。ModelScope 托管大量开源模型。

## 支持的请求类型

- 聊天补全（Chat Completion）
- 流式聊天补全（Chat Completion Streaming）
- 模型列表（List Models）

## 限制

- 不支持文本补全（Text Completion）
- 不支持 Embedding
- 不支持图片生成
