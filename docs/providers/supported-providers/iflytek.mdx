# 讯飞星火 (iFlytek Spark)

科大讯飞星火大模型的 OpenAI 兼容 API 接入。

## 配置

```json
{
  "providers": {
    "iflytek": {
      "network_config": {
        "base_url": "https://spark-api-open.xf-yun.com"
      }
    }
  }
}
```

## API Key

在 [讯飞开放平台](https://console.xfyun.cn/services/cbm) 创建 API Key。

环境变量：`IFLYTEK_API_KEY`

## 模型

- `generalv3.5`
- `generalv3`
- `pro-128k`

## 支持的请求类型

- 聊天补全（Chat Completion）
- 流式聊天补全（Chat Completion Streaming）
- 模型列表（List Models）

## 限制

- 不支持文本补全（Text Completion）
- 不支持 Embedding
- 不支持图片生成
