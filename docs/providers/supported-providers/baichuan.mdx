# 百川智能 (Baichuan)

百川智能大模型平台的 OpenAI 兼容 API 接入。

## 配置

```json
{
  "providers": {
    "baichuan": {
      "network_config": {
        "base_url": "https://api.baichuan-ai.com"
      }
    }
  }
}
```

## API Key

在 [百川智能开放平台](https://platform.baichuan-ai.com) 创建 API Key。

环境变量：`BAICHUAN_API_KEY`

## 模型

- `Baichuan4-Turbo`
- `Baichuan4`

## 支持的请求类型

- 聊天补全（Chat Completion）
- 流式聊天补全（Chat Completion Streaming）
- 模型列表（List Models）
