## FAIL 项详细

### R-1 — design_alignment FAIL

- **任务** (tasks.md §22.11)：「修改 `ui/app/workspace/routing-rules/views/routingRuleSheet.tsx`、`routingRuleInfoSheet.tsx`、`tree/views/node/rfRuleNode.tsx`，scope 收窄为 `virtual_key / global`，删除 customer/team/user scope 分支」
- **设计** (design.md)：`RoutingRuleScope` 仅保留 `virtual_key / global`，树视图删除 team/customer/user 渲染分支
- **遗漏 1**：`ui/app/workspace/routing-rules/views/routingRuleInfoSheet.tsx` **未在 diff 中修改**（`git diff name-status` 无条目）。当前代码仍调用：
  ```ts
  useGetTeamQuery(scopeId as string, { skip: scope !== "team" || !scopeId })
  useGetCustomerQuery(scopeId as string, { skip: scope !== "customer" || !scopeId })
  if (scope === "team") return teamData?.team?.name
  if (scope === "customer") return customerData?.customer?.name
  ```
  —— 把 `team`/`customer` 字符串字面量留在 OSS 代码中（design 已声明不再支持该 scope）。
- **遗漏 2**：`ui/app/workspace/routing-rules/tree/views/node/rfRuleNode.tsx` **未在 diff 中修改**。当前条件渲染仍为通用 `rule.scope !== "global" && rule.scope_id`，未收窄为 `rule.scope === "virtual_key"`。
- **遗漏 3**：`ui/app/workspace/routing-rules/tree/views/constants.ts` `SCOPE_CONFIG` 仍含 `team: { label: "Team", ... }` / `customer: { label: "Customer", ... }`，`SCOPE_ORDER` 仍为 `["virtual_key", "team", "customer", "global"]`——图例 / 类定义残留。
- **建议**：
  - `routingRuleInfoSheet.tsx`：删除 `useGetTeamQuery` / `useGetCustomerQuery` 分支与 `useScopeName` 中的 team/customer 分支；只保留 `useGetVirtualKeyQuery`。
  - `rfRuleNode.tsx`：把 `rule.scope !== "global" && rule.scope_id` 收窄为 `rule.scope === "virtual_key" && rule.scope_id`。
  - `tree/views/constants.ts`：从 `SCOPE_CONFIG` / `SCOPE_ORDER` 删除 team & customer 条目。

### R-5 — test_contract FAIL

- **文件**：`ui/lib/enterprise-stripping.test.ts`（新增 `ui/lib/enterprise-stripping.test.ts`）
- **问题**：`describe("21.4 — no false in sidebar")` 的实现断言 sidebar.tsx 内不应出现字符串 `"false"`。但 sidebar.tsx 当前保留 20 处合法布尔字面量 `false`（如 `useState(false)` 初始值、`onClick={() => setFlyoutOpen(false)}`、`subItem.hasAccess === false`）。运行 `npx vitest run` 时该用例必然失败，不构成任何有效契约检查。
- **建议**：重写 21.4 的断言，比如断言 `IS_ENTERPRISE` 不存在；或者断言特定已知企业版菜单项（Proxy / Branding / License Info）不存在；或断言遗留 `enterprise-only` 注释已被清除。再不济，删除该用例。
