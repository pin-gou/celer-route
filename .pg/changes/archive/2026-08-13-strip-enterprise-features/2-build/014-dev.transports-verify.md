# 014-dev.transports:verify 验证报告

## 验证结果：FAIL

### 执行摘要

dev.transports 验证失败。`transports` 模块本身代码变更正确（config.schema.json 清理、enterprisePlugins 删除、largePayloadHook 移除），但变更在 `core/schemas/bifrost.go` 中删除了 20+ enterprise-only BifrostContextKey 常量后，**未同步清理 plugins 目录中对这些常量的引用**，导致整个 Go workspace 编译失败，服务无法启动，所有 V-* 验证项无法执行。

## 14.4 V-transports-N 验证项

### V-transports-1: config.schema.json 同步校验

**结果**: ❌ FAIL (blocked by build failure)

- `BifrostContextKeyGovernanceBusinessUnitID/Name`
- `BifrostContextKeyGovernanceTeamIDs/Names`
- `BifrostContextKeyGovernanceCustomerIDs/Names`
- `BifrostContextKeyGovernanceScopedCustomerID`
- `BifrostContextKeyUserID/Name/Email`
- `BifrostContextKeyClusterNodeID`
- `BifrostContextKeyGuardrailDebug`
- `BifrostContextKeyRedactionData`
- `BifrostContextKeyLargePayloadMetadata`
- `BifrostContextKeyLargePayloadRequestThreshold`
- `BifrostContextKeyDeferredUsage`

这些常量被以下 plugins 引用但未同步清理：
- `plugins/telemetry/main.go` (9 处)
- `plugins/logging/main.go` (11 处)
- `plugins/otel/main.go` (7 处)
- `plugins/governance/main.go` (7 处)
- `plugins/governance/store.go` (2 处)

## 修复建议

`core/schemas/bifrost.go` 中删除 enterprise-only BifrostContextKey 常量后，需要在以下文件中同步删除对这些常量的引用：

1. **plugins/telemetry/main.go** - 删除所有 `BifrostContextKeyGovernanceBusinessUnitID/Name/IDs/Names`、`BifrostContextKeyGovernanceTeamIDs/Names`、`BifrostContextKeyGovernanceCustomerIDs/Names` 的引用
2. **plugins/logging/main.go** - 删除所有 `BifrostContextKeyUserID/Name`、`BifrostContextKeyGovernanceBusinessUnitID/Name`、`BifrostContextKeyDeferredUsage`、`BifrostContextKeyLargePayloadRequestThreshold` 的引用
3. **plugins/otel/main.go** - 删除所有 `BifrostContextKeyGovernanceTeamIDs/Names`、`BifrostContextKeyGovernanceCustomerIDs/Names`、`BifrostContextKeyGovernanceBusinessUnitIDs/Names/ID/Name` 的引用
4. **plugins/governance/main.go** - 删除所有 `BifrostContextKeyUserID`、`BifrostContextKeyGovernanceScopedCustomerID`、`BifrostContextKeyLargePayloadMetadata` 的引用
5. **plugins/governance/store.go** - 删除所有 `BifrostContextKeyGovernanceScopedCustomerID` 的引用
