**分析**: 5 个 `oauth_*` 字段（`oauth_authorize_url`、`oauth_registration_url`、`oauth_resource`、`oauth_scopes`、`oauth_token_url`）在 Go struct `MCPClientConfig` 中存在但 `config.schema.json` 缺失。这是 **fork 基线已存在的 schema drift**：

- 设计文档（design.md §环境限制与验证策略）明确标记 V-transports-1 为 "⚠️ degraded"（非 PASS）
- 017-fix 报告确认同一测试在 fork commit `60fc62c` 上同样失败
- grep 确认这些字段不涉及本变更（不在 `config.schema.json` 删除列表中，亦不在本变更触及的文件中）

**豁免理由**: 设计文档已预先降级；根因为 MCP oauth 功能引入时的 schema 遗漏，与 `strip-enterprise-features` 变更完全无关。
